# 특별실 이용 현황 공유 및 확인 서비스

같은 시간·같은 장소에 특별실 신청이 겹쳐 불편을 겪는 학생들을 위해,
특별실 사용 상태를 신청하고 전체 이용자에게 시간표 형태로 보여 주는 서비스입니다.

## 진행 단계
1. **프론트 개발** (1~5회차): 더미 데이터로 동작하는 화면 완성, Vercel 배포
2. **서버·DB 연동** (6~8회차): Supabase로 실제 회원가입/신청/취소 기능 구현

## 폴더 구조
```
index.html     신청 현황 표 + 신청하기 폼
mypage.html    내가 신청한 내역
css/style.css  스타일
js/script.js   동작 스크립트
```

## 설계 메모 (6회차 DB 설계 시 반영)
- 학번(예: 2207)은 학년+반+번호를 담고 있어 학년이 바뀌면 값이 바뀐다.
- 회원 테이블의 기본키(고유 식별자)는 학번이 아니라 별도 id(Supabase auth의 user id)로 두고,
  학번은 그 위에 얹히는 "수정 가능한 일반 필드"로 저장한다.
- 로그인은 학번+비밀번호로 하되, 내부적으로 계정을 구분하는 값은 학번이 아니게 설계할 것.
